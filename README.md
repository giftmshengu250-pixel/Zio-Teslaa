# Tesla Website Clone 

A static Tesla-inspired website clone built with **HTML and CSS** to practise and demonstrate my understanding of web structure, layout, styling, and responsive design.

The goal of this project was not to build a fully functional Tesla website, but to recreate the visual structure and overall layout of a modern automotive website while strengthening my front-end development fundamentals.

🔗 **Live Demo:** https://tecla-clone.netlify.app/

## About the Project

This project recreates the structure of a Tesla-style landing page using HTML and CSS.

I focused on breaking the website into clear sections and using HTML to create the structure of the page, while CSS was used to control the layout, spacing, typography, positioning, and visual appearance.

The project helped me understand how professional websites can be broken down into smaller sections such as:

* Navigation bar
* Hero sections
* Product/content sections
* Call-to-action areas
* Footer

The website is currently **static**, meaning there are no JavaScript interactions or dynamic functionality. The main purpose of the project was to demonstrate my understanding of HTML and CSS fundamentals.

##  Features

##  Challenges I Encountered

One of the main challenges I encountered was getting the different sections to visually match the reference design. Recreating a professional website is more than simply placing images and text on a page. Small differences in spacing, sizing, positioning and typography can significantly change how the final design looks.

Another challenge was working with large background images and making sure that the content remained positioned correctly across different screen sizes.

I also had to spend time understanding CSS positioning and layout techniques instead of relying on trial and error. This helped me become more comfortable with concepts such as Flexbox, spacing, sizing, positioning and responsive media queries.

##  How I Overcame the Challenges

I approached the problems by breaking the website down into smaller sections instead of trying to build the entire page at once.

For example, I worked on the navigation, hero section and individual content sections separately before putting everything together. I also used browser developer tools to inspect the layout and make adjustments to spacing, sizing and positioning.
